# Full-Stack Portfolio Website

## Structure
- `frontend/` → React app (deployed on Vercel)
- `backend/` → Node.js + Express + PostgreSQL (deployed on Render)

## Live Links
- Frontend (Vercel): https://portfolio-site-nu-two-30.vercel.app
- Backend (Render): https://portfolio-backend-zqsf.onrender.com
- Contacts API: https://portfolio-backend-zqsf.onrender.com/contacts

## Features
- Portfolio sections (About, Projects, Contact)
- Contact form integrated with backend
- Messages stored in Postgres and viewable via `/contacts`
